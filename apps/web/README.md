# apps/web

Front-end do movietickets — React + Vite.

SPA: catálogo de filmes/sessões, mapa de assento, checkout, conta do usuário, painel admin.

Ainda não inicializado — scaffold do projeto Vite entra na primeira feature.

## Rodar

```bash
pnpm dev:web
```

## Testes

Vitest + React Testing Library, unitários e de integração de componentes/fluxos.

```bash
pnpm --filter web test
```
